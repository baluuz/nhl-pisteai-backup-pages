NHL-PisteAI Backup

A private backup tool for one person's hobby project.

NHL-PisteAI Backup is a private, personal-use backup tool. It is not offered to the public and has no public user registration or sign-up.

What it does

  • It backs up the files of a personal NHL statistics research project (prediction records, results, model files and configuration) to the owner's own Google Drive.
  • Backups are encrypted before they are uploaded, so Google Drive only ever stores encrypted files.
  • It uses the Google Drive API through the open-source rclone program, running on the owner's own server.
  • It requests only the drive.file permission, which limits access to files the app itself creates.
This project is an independent hobby project. It is not an official product or service of Google or of the NHL, and it is not affiliated with or endorsed by either.
