Privacy Policy

NHL-PisteAI Backup · last updated 10 November 2026

NHL-PisteAI Backup is a private tool that one individual uses to back up their own hobby project to their own Google Drive. It is not offered to other users. This policy describes what the tool does.

What the app uses Google Drive for

The app uses the Google Drive API to store and restore the owner's personal backup files in a dedicated folder of the owner's own Google Drive. The backups contain files of a personal NHL statistics research project. They do not contain data about other people.

Permission requested

The app requests the https://www.googleapis.com/auth/drive.file permission. With this permission the app can access only files and folders that the app itself created, or that the user has explicitly opened with or shared with the app. The app does not need and does not request access to any other files in the owner's Google Drive.

Encryption

Backup files are encrypted on the owner's server before they are uploaded. File contents and file names are encrypted, so Google Drive stores only encrypted data. The encryption keys are not stored in Google Drive.

Credentials

Google OAuth credentials (an access/refresh token and the OAuth client details) are used only to keep the connection to Google Drive working. They are stored on the owner's own private server with restricted file permissions, and they are never published on this website or anywhere else.

Data sharing

The app does not sell data, does not use data for advertising, and does not share data with third parties. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website is static. It does not use cookies, analytics, advertising or tracking scripts, and it does not collect any information from visitors. It is hosted on GitHub Pages; GitHub may process technical data such as IP addresses when pages are requested, as described in GitHub's privacy statement.

Revoking access and deleting data

The owner can revoke the app's access to Google Drive at any time at myaccount.google.com/permissions. Backup files can be deleted by deleting the backup folder in Google Drive.

Changes and contact

If this policy changes, the date above will be updated. Questions can be sent by opening an issue at the project's GitHub page.
